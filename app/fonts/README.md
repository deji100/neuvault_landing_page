# Local site fonts

Variable Latin WOFF2 fonts served by Google Fonts, bundled to avoid network font downloads during Next.js compilation. All of them use the SIL Open Font License; their licenses are included here.

- Bricolage Grotesque: weights 200–800
- Instrument Sans: weights 400–700
- Inter: weights 400–700
- Baskervville: 400 and 500, two static latin files (the closing Signoff line):
  - 400: https://fonts.gstatic.com/s/baskervville/v20/YA9Br0yU4l_XOrogbkun3kQ6vLFYXmpq8sRsYuDrigS4dD9APk2igw.woff2
  - 500: https://fonts.gstatic.com/s/baskervville/v20/YA9Br0yU4l_XOrogbkun3kQ6vLFYXmpq8sRsYtLrigS4dD9APk2igw.woff2

Source CSS: https://fonts.googleapis.com/css2?family=Bricolage+Grotesque:wght@200..800&family=Instrument+Sans:wght@400..700&family=Inter:wght@400..700&display=swap
and https://fonts.googleapis.com/css2?family=Baskervville:wght@400;500&display=swap

Font source and licenses: https://github.com/google/fonts/tree/main/ofl
