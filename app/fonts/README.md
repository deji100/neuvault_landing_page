# Local site fonts

Variable Latin WOFF2 fonts served by Google Fonts, bundled to avoid network font downloads during Next.js compilation. All three fonts use the SIL Open Font License; their licenses are included here.

- Bricolage Grotesque: weights 200–800
- Instrument Sans: weights 400–700
- Inter: weights 400–700

Source CSS: https://fonts.googleapis.com/css2?family=Bricolage+Grotesque:wght@200..800&family=Instrument+Sans:wght@400..700&family=Inter:wght@400..700&display=swap

Font source and licenses: https://github.com/google/fonts/tree/main/ofl
