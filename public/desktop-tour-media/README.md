The accommodation PDF is an original travel-planning document for the walkthrough, generated by scripts/create-kyoto-stay-pdf.py. It contains the trip dates, room requirements, arrival/departure plans, daily outline and booking checks; it is not a supplier-issued booking confirmation.

The webpage preview loads https://en.wikivoyage.org/wiki/Kyoto live in the original native preview host. No local copy or abbreviated substitute is used.
