The 38-second Reminders demonstration is built from the actual desktop SmartSuggestionsPage, AppSidebar, GlobalIntakePreview, DesktopSmartDocHandler, DesktopResurfaceSection, DesktopSectionShell, VaultSubgroupDocumentCard, ReminderCountdown and FlipCountdown. Native JSX and CSS are preserved; the bundle records source hashes and asserts that the controller injection does not change JSX. The Vault grid uses the desktop’s own desktop-vault-subgroup-document-grid context and unchanged document cards for the example travel files. The native documentThumbnails module supplies type classification and artwork sizing; PDFs are never routed through video controls.

The walkthrough starts with two AI-detected dates and two manual reminders. It opens a detected date's document and an existing yearly manual schedule, then opens Japan travel bookings.pdf from Vault. It shows importance, an explanatory note, and a custom date and time. The new schedule is one-off, exactly as the desktop custom-date handler defines it; the existing manual schedule demonstrates yearly recurrence. The native automatic-save status confirms the schedule, and the new manual reminder appears without an AI detected badge. Mark done clears a handled detected date. Cursor movements take 350ms and typing takes 24ms per character; the remaining pauses let visitors read the result.

scripts/native-reminders/build.mjs replaces database, authentication, queue, account and notification IO with local example records. It compiles the real desktop components with the desktop Vite/Tailwind dependencies. The controlled clock is fixed to November 12, 2026 in the embedded document, with its seconds following the tour, so countdowns and example dates remain consistent. It never changes the parent page's Date or sends real reminders, writes to an account or creates calendar events.

RemindersDemo.tsx owns the parent playback controls and iframe. The embedded tour is automated and ignores trusted input, matching the other demos. Paused seeks/replay restore canonical state; offscreen/hidden tabs pause; reduced motion starts at the final still; the whole desktop canvas scales on mobile. The iframe and cursor share native screen coordinates and portal geometry. Detail dialogs use the original layout and date/time inputs.

Run `npm run build:reminders` after changing the tour or desktop source. Publishing the generated assets preserves the old bundle until the new assets and manifest are ready, so local development does not temporarily lose its manifest. Run `npm run check:reminders` with a local Chrome CDP endpoint; PREVIEW_URL and CDP_URL override defaults. The browser checks cover native source fidelity, existing AI/manual reminders, every setup control, native custom-date semantics and saved result, playback, replay, offscreen pause and mobile/reduced motion.
